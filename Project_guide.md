# Hairitage Barbershop - Project Guide

## Introduction

This document explains how the Hairitage Barbershop project was built, the purpose of every file and folder, and how each technology works together.

The project started as a simple front-end website using HTML, CSS, and JavaScript. It was later converted into a full-stack web application by adding Node.js, Express, and PostgreSQL.

# Folder and File Explanation

## css/

This folder contains all the CSS files used to style the website.

### styles.css

This file controls:

- Colors
- Fonts
- Layout
- Spacing
- Buttons
- Responsive Design
- Animations

Without this file, the website would appear as plain HTML without styling.

---

## images/

This folder stores every image used by the website.

Examples include:

- Banner image
- Gallery images
- Logo
- Icons

Keeping images inside one folder makes the project organized.

---

## js/

This folder contains JavaScript files.

### script.js

This file adds interactivity to the website.

It is responsible for:

- Displaying services dynamically
- Creating the appointment wishlist
- Saving wishlist data using Local Storage
- Removing wishlist items
- Validating the booking form
- Sending booking information to the backend using the Fetch API
- Showing booking success messages
- Displaying and hiding the banner caption

Without JavaScript, the website would only display information and would not respond to user actions.

---

## node_modules/

This folder contains all packages installed using npm.

Examples include:

- Express
- pg
- dotenv

This folder is created automatically.

It should never be edited manually.

It should never be uploaded to GitHub.

---

## .env

This file stores sensitive information.

Examples:

- Database username
- Database password
- Database name
- Database host
- Database port

The .env file keeps passwords outside the source code.

Git ignores this file so it is never uploaded publicly.

---

## .gitignore

This file tells Git which files and folders should not be uploaded.

Current ignored items:

- node_modules/
- .env

This protects large files and sensitive information.

---

## db.js

This file creates the connection between Node.js and PostgreSQL.

Its responsibilities include:

- Importing the PostgreSQL package
- Creating a database connection pool
- Exporting the pool so other files can use it

Without db.js, the application cannot communicate with PostgreSQL.

---

## index.html

This is the main webpage.

It contains:

- Navigation bar
- Hero section
- About section
- Services section
- Wishlist
- Gallery
- Contact form
- Footer

HTML provides the structure of the website.

---

## LICENSE

This file explains how other people may use this project.

The project currently uses the MIT License.

---

## package.json

This file contains information about the Node.js project.

It stores:

- Project name
- Version
- Author
- Installed dependencies
- Scripts
- Repository information

npm uses this file to manage the project.

---

## package-lock.json

This file records the exact versions of every installed package.

It ensures that every developer installs identical versions of dependencies.

This file is automatically generated by npm.

---

## README.md

The README is the main documentation shown on GitHub.

It explains:

- Project overview
- Features
- Technologies
- Installation
- Usage

---

## server.js

This is the backend server.

It is responsible for:

- Starting Express
- Serving website files
- Receiving booking requests
- Connecting to PostgreSQL
- Saving bookings into the database
- Sending responses back to the browser

The server acts as the bridge between the website and the database.
